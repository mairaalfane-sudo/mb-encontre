Aprenda FlexBox

Template basico para iniciantes dominarem o css flexbox de forma pratica

Principais conceitos

Display Flex

O primeiro passo e defenir display:flex no container pai para ativar o sitemas de layout flexivel.

Justify Content

Controla o alinhamento dos itens ao longo do eixo principal(horizontal por padrao).

Align Items

Controla o alinhamento dos itens ao longo do eixo transversal (vertical por padrao).

Flex Wrap

Permite que os itens quebram para uma nova linha quando nao ha espaco suficiente

Layout Responsivos

O Flexbox forma muito facil
criar layouts que se adaptam a diferentes tamanhos de tela. Os itens se reorganizam automaticamente conforme o espaco disponivel.

Alinhamento perfeito

Centralize elementos vertical e horizontalmente
com apenas duas propriedades CSS. Algo que antes era complexo agora e simples.

Distribuicao de Espaco

Controle como o espaco e destribuido entre os elementos. criando layouts harmoniosos e bem balenceados
